O que é o Bounded-PCP?

1. O problema de Post

Proposto por Emil Post em 1946. A entrada é um conjunto finito de peças de dominó, cada uma com uma palavra no topo e outra na base:

D = { [t1 / b1], [t2 / b2], …, [tn / bn] },  ti, bi ∈ Σ+

A pergunta é se existe uma sequência de índices i1, …, im (com m ≥ 1, repetições permitidas) tal que os topos concatenados formem a mesma palavra que as bases concatenadas:

ti1 ti2 … tim = bi1 bi2 … bim

2. Sem limite, é indecidível

Se m pode ser qualquer tamanho, não existe algoritmo que responda sim ou não para toda instância. A prova reduz o problema da aceitação de Máquinas de Turing ao PCP: as peças são construídas para simular a computação da máquina, e uma correspondência existe se e somente se a máquina aceita a entrada (Sipser, seção 5.2).

3. Com limite K

Perguntando “existe correspondência com no máximo K peças?”:

  • Fica decidível. Há no máximo |D| + |D|2 + … + |D|K sequências, então uma busca exaustiva sempre termina.
  • É NP-completo. Está em NP porque, dada uma sequência candidata, basta concatenar e comparar em tempo polinomial. É NP-difícil (catalogado em Garey & Johnson, 1979).

4. Podas usadas aqui

Raiz
Só começa por peças em que ti é prefixo de bi ou o contrário.
Prefixo
Ao anexar uma peça, se topo e base passam a divergir em algum caractere, o ramo morre.
Estado
O que importa para o futuro é só o excedente (qual fita está adiantada e com quais caracteres). Se esse excedente já apareceu, o ramo é redundante. Como a busca é em largura, a primeira ocorrência é sempre a mais curta.
K
Nós com K peças não geram filhos.
